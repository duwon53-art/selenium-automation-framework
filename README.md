📌 프로젝트 개요
이 저장소는 반복적인 Regression Test의 효율을 개선하기 위해 Python, Selenium, PyTest를 활용하여 구축한 UI 테스트 자동화 프로젝트입니다.

실제 QA 업무에서 반복적으로 수행되는 테스트 시나리오를 기반으로 자동화 대상을 선정하고, Page Object Model 구조를 적용하여 유지보수와 재사용성을 고려한 테스트 구조를 설계했습니다.

특히, 주문 기능과 같이 반복 실행이 필요한 핵심 사용자 흐름을 
E2E 시나리오로 자동화하여 테스트 안정성을 검증했습니다.

🧩 테스트 대상 및 범위
대상: 웹 서비스 (로그인 ~ 주요 기능 흐름)
자동화 범위:
로그인 / 로그아웃
핵심 사용자 시나리오 기반 주문 기능 테스트
반복 실행이 필요한 회귀 테스트

자동화 제외 범위:
UI 변경이 잦은 영역
일회성 또는 탐색적 테스트

🛠 기술 스택
- Python: 자동화 스크립트 작성
- Selenium WebDriver: UI 기반 사용자 시나리오 자동화
- Pytest: 테스트 실행 및 구조화
- Git/GitHub: 버전 관리 및 포트폴리오 관리

🔍 QA 관점에서의 고민

모든 테스트를 자동화하지 않았습니다.
자동화 대상은 아래 기준으로 선정했습니다:
- 반복 실행 빈도가 높은 기능
- 서비스 핵심 비즈니스 로직
- 유지보수 비용 대비 효율

자동화는 목표가 아니라 품질을 유지하기 위한 수단이라고 생각합니다.
